# `saywnd`

<!--dt-desc-start-->
Holds a member the returns the title of the say window
<!--dt-desc-end-->

## Members
<!--dt-members-start-->
/// member | string Title
Returns the current title of the say window
///

/// member | string LastSay
The last /say received
///

/// member | string LastSpeaker
The last character to speak over /say
///

/// member | string To String
///

<!--dt-members-end-->

## Examples
<!--dt-examples-start-->
`/echo ${SayWnd.Title}`
<!--dt-examples-end-->
